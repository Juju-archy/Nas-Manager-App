L'app communique désormais avec TrueNAS via son API JSON-RPC WebSocket (/api/current) au lieu de l'API REST dépréciée, supprimée dans TrueNAS 27. Nécessite TrueNAS Scale 25.04 ou plus récent (testé sur 25.10) : les versions antérieures (24.10 et avant) ne peuvent plus se connecter. Une clé d'API peut être collée dans le champ mot de passe (HTTPS uniquement). Merci à naorleizer pour cette migration.
