The app now talks to TrueNAS over its WebSocket JSON-RPC API (/api/current) instead of the deprecated REST API, which TrueNAS 27 removes. Requires TrueNAS Scale 25.04 or later (tested on 25.10): older versions (24.10 and before) can no longer connect. An API key can be pasted in the password field (HTTPS only). Thanks to naorleizer for this migration.
