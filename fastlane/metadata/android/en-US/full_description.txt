NasManager is an unofficial companion client for TrueNAS® SCALE servers. It talks directly to your server's REST API (/api/v2.0): no account to create, no intermediate server, no tracking, no ads.

<b>Dashboard</b>
<ul>
<li>System information, CPU (total and per core), memory (Services / ZFS Cache / Free, same breakdown as the TrueNAS web dashboard), pools and storage</li>
<li>CPU, memory and pools refreshed every 2 seconds</li>
</ul>

<b>Reporting graphs</b>
<ul>
<li>CPU: usage (average and per core), temperature, load average</li>
<li>Memory: available, used, ZFS cache (ARC)</li>
<li>Time range from 5 minutes to 1 month, optional auto-refresh every 5 seconds</li>
<li>Pools: space breakdown, topology, usable capacity, status, fragmentation, last scrub</li>
<li>Per-disk detail: I/O and temperature graphs, with max / mean / min</li>
</ul>

<b>Alerts</b>: list of active alerts with a badge in the menu, and a "Dismiss" button per alert (applied on the server, like in the web interface).

<b>Apps</b>: installed apps with their status, update one app or all of them at once.

<b>System</b>: general settings, network configuration and interfaces, boot environments (read-only).

<b>Security and privacy — please read</b>
<ul>
<li><b>Authentication</b>: TrueNAS SCALE has no REST login route, so the app uses HTTP Basic Auth: your username and password are sent with every request to your server. Use a TrueNAS account dedicated to the app with reduced permissions, rather than your main admin account.</li>
<li><b>Unencrypted HTTP</b>: HTTPS is recommended. Plain HTTP (IP address or hostname) is possible, but only after you explicitly check a box accepting the risk: your credentials then travel in clear text on the network.</li>
<li><b>Credential storage</b>: by default, credentials are only kept in memory. If you check "Stay logged in", they are saved on the device, encrypted with a key held in the Android Keystore (EncryptedSharedPreferences). "Stay logged in" is unavailable for an HTTP address, so a saved password is never sent automatically in clear text.</li>
<li><b>Network connections</b>: the app only connects to the server address you enter, plus, on the Apps screen, the public TrueNAS icon CDN (media.sys.truenas.net) to display app icons. Your credentials are never sent to that CDN.</li>
</ul>

<b>Requirements and limits</b>
<ul>
<li>A TrueNAS SCALE server reachable from your phone. With a self-signed certificate (TrueNAS default), install it in Android's security settings for HTTPS to work.</li>
<li>No per-app CPU / memory / network usage: TrueNAS only exposes these metrics over WebSocket, not REST.</li>
<li>"Discover Apps" (catalog browsing and install) is not available yet.</li>
<li>Interface in English.</li>
</ul>
